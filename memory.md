# Memory — Sesi Perbaikan Modal Edit Video

> Terakhir diperbarui: **25 Jul 2026** · Konteks: perbaikan & penambahan fitur modal **Edit Video** (`#videoEditorModal`) di PLAYLY DASHBOARD.
> File ini ringkasan kerja supaya sesi berikutnya tidak perlu menelusuri ulang dari nol.

## 1. Arsitektur singkat

- Markup modal: `app/_legacy/index-markup.ts` (string raksasa `INDEX_MARKUP`, di-render apa adanya oleh `app/_legacy/IndexPage.tsx`).
- Logika: `public/legacy/script.js` (~69k baris; pola IIFE bertanggal, saling patch).
- Style: `public/legacy/styles.css` (~82k baris; blok baru **ditambahkan di akhir file**, scoped `#videoEditorModal`).
- Dev (`next dev`) menyajikan file **non-min**; `.min.*` dibuat ulang oleh `npm run minify:legacy` saat `prebuild` (jadi tak perlu minify manual).
- Cache-bust `?v=` dihitung dari hash isi file tiap render di dev → edit JS/CSS langsung kebaca setelah refresh.
- Validasi: `npm run check:css` (keseimbangan brace CSS) · `node --check public/legacy/script.js` · `npm run type-check`.

## 2. Struktur modal saat ini

```
.video-editor-panel (grid 2 kolom: stage | controls, header & footer full-width)
├─ .ve-stage (KIRI): video → #vePreviewBtn → #veCropApplyRow (baru) → section TRIM
└─ .ve-controls (KANAN): tabs (Advance/Warna/Text Overlay) → panel tab
   ├─ Advance: Aspect Ratio/Crop pills + Posisi X/Y, Zoom, Rotate, Flip
   ├─ Warna: slider color + preset filter
   └─ Text Overlay: teks, posisi, ukuran (slider+angka+Preset sebaris), warna
Footer: Reset | Batal, Export Video — #veDirtyConfirm (popup dirty guard) anak terakhir panel
```
